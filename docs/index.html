# 视频学习笔记草稿

来源：离线演示（原创示例字幕，无对应第三方视频）

## 字幕摘录

以下仅为前三段字幕摘录，不代表视频重点，也不是 AI 摘要。

- [00:00] 学习一项新工具时，先记录一个具体问题。
- [00:12] 用一次小实验验证自己的理解，并保留观察结果。
- [00:26] 最后整理还有哪些地方需要回看，而不是急着下结论。

## 我的理解

回看原视频后，用一句话写下主线。

## 待核实

- 作者的判断有什么理由或例子？
- 人名、数字和关键结论是否准确？
- 是否遗漏了前提、转折或相反观点？
